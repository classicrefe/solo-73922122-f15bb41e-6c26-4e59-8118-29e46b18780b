# 量具重复性与再现性（GRR）分析

机加工车间量具评估小工具：Flask 网页 + SQLite 保存一场试验。
登记检验员与样件 → 网页录入每人每件两次毫米读数 → 读数齐全后自动做
带交互项的双因素方差分析 → 样件磕伤可原位置换件，只重测新件，旧报告转历史备查。

## 功能

- **登记试验**：2～4 名检验员、3～8 件样件（一次只保存一场试验）。
- **读数录入**：每人对每件测两次（毫米）。同一测次原值重报只记一次；异值退回；非法数值退回。
- **方差分析**：读数齐全才计算。列出重复测量（重复性）、检验员（再现性）、
  样件×检验员交互、样件的方差分量，负分量按零计；附 SS/df/MS 表与所用读数。
- **缺测提示**：试验台与报告页均列出待补项（位置/编号/检验员/测次）。
- **换件复测**：原位置换入新编号，旧件下线、读数保留备查，现行报告转历史；
  旧件迟到读数拒收，其他样件已打开的表单仍可提交；只需重测新件。
- **一致性**：样件、读数、现行报告对应同一已提交状态（单事务提交）；
  提交失败整体回滚，原进度保留。

## 本地运行

```bash
pip install -r requirements.txt
python run.py                 # http://localhost:8000
DEMO_SEED=1 python run.py     # 载入演示数据（3 人 × 5 件，报告已生成）
```

## Docker Compose 演示（换件复测）

```bash
docker compose up --build     # http://localhost:8000
```

首次启动自动载入演示试验（读数齐全、现行报告已生成）。在网页上演示换件复测：

1. 打开 <http://localhost:8000> ，点「现行报告」查看既有方差分量。
2. 回到试验台，在「样件更换」选位置 3（P-103），输入新编号 `P-103B`，换入新件。
3. 报告页出现 6 项待补项（3 名检验员 × 2 测次），其余样件读数不受影响。
4. 在录入表格填入新件 6 个读数并提交（旧件 P-103 的迟到读数会被拒收）。
5. 读数齐全后自动生成新现行报告；「历史报告」中旧报告标为历史，
   点开仍可查到当时所用读数。


## 结构

```
grr/
  app.py      Flask 路由（试验台/读数/换件/报告/历史）
  service.py  业务逻辑与事务（登记、录入、换件、报告生成）
  anova.py    带交互项的双因素方差分析（纯函数）
  db.py       SQLite 连接与表结构
  seed.py     演示数据
  templates/  页面模板
run.py        启动入口
tests/        pytest 关键流程自测
```
